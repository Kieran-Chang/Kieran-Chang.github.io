idol-report 隱私權政策

idol-report 是個人使用的工具，只有開發者本人會用自己的 Google 帳號授權。

使用的資料

工具透過 YouTube Data API 讀取開發者帳號裡的播放清單名稱和清單內的影片，並把開發者選擇的歌曲加進指定的播放清單。

資料的保存與分享

授權憑證只存放在開發者自己的電腦上。工具不會蒐集其他人的資料，也不會把 YouTube 資料賣給或分享給第三方。

撤銷授權

可以隨時到 Google 帳戶權限頁面 撤銷 idol-report 的存取權。

English

idol-report is a personal tool authorized only by its developer's own Google account. It uses the YouTube Data API to read the developer's playlists and add selected songs to a chosen playlist. Credentials are stored only on the developer's computer. No data is collected from other people, and YouTube data is not sold or shared with third parties. Access can be revoked at any time from the Google Account permissions page.
